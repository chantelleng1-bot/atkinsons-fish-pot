# Atkinson's Fish Pot

Website for **Atkinson's Fish Pot**, a family-run Jamaican seafood spot in White River, St. Ann, Jamaica, just outside Ocho Rios.

The site is a single static page: menu with prices, photo gallery, guest ratings, hours with a live open/closed indicator on Jamaica time, location, and links to call or follow on Instagram ([@fishpotwr](https://www.instagram.com/fishpotwr/)).

## Files

- `index.html` – the whole site (HTML, CSS and JavaScript in one file)
- `images/` – food and restaurant photos used on the page

## Running it

No build step. Open `index.html` in a browser, or serve the folder with any static host.

To publish it with GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
